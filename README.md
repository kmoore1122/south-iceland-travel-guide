# 🧊 Southern Iceland Travel Guide

An interactive travel planning tool for Iceland's South Coast Ring Road — built as a single self-contained HTML file that works in any browser, on any device.

## ✨ Features

- **Interactive Map** — 24 clickable markers with descriptions, tips, and photo slots. Filter by type (waterfalls, glaciers, geothermal, beaches, etc.)
- **9-Day Itinerary** — Full day-by-day breakdown with morning/afternoon/evening activities
- **Stay & Dining** — Accommodations, restaurant recommendations, and practical tips
- **Natural Wonders** — Dedicated waterfall guide, Northern Lights viewing spots, and photography tips for every type of shot
- **Route Planner** — Build custom driving routes with estimated times and distances
- **Packing List** — Categorized checklist with persistent state (checks are saved)
- **Budget Tracker** — Editable line-item estimates with live totals
- **Mobile Responsive** — Works on desktop, tablet, and phone
- **Photos baked in** — Key waterfall and location photos embedded directly

## 🗺 Route Covered

**Reykjavik → Golden Circle → Vik → East Iceland (Glacier Lagoon) → Stokkseyri**

Highlights include:
- Blue Lagoon
- Gullfoss, Skógafoss, Seljalandsfoss, Kvernufoss, Gljúfrabúi, Brúarfoss, Múlagljúfur
- Reynisfjara Black Sand Beach & Dyrhólaey
- Jökulsárlón Glacier Lagoon & Diamond Beach
- Crystal Blue Ice Cave (Katla/Vatnajökull)
- Þingvellir National Park

## 🚀 How to Use

Just open `Southern-Iceland-Travel-Guide.html` in any browser — no installation, no internet required (except for map tiles).

**Live version:** [kmoore1122.github.io/south-iceland-travel-guide](https://kmoore1122.github.io/south-iceland-travel-guide/)

## 📷 Adding Photos

Click any image placeholder on the Map or Waterfalls tab to upload your own photos. They save automatically in your browser's localStorage.

## 🛠 Built With

- [Leaflet.js](https://leafletjs.com/) — Interactive map
- [Lucide Icons](https://lucide.dev/) — Line icon set
- [CartoDB Dark Matter](https://carto.com/basemaps/) — Map tiles
- Vanilla HTML, CSS, JavaScript — no frameworks
